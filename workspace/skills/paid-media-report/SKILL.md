# Weekly Paid Media Report

## Structure

1. **Header** - reporting window dates and the data-complete-through date.
2. **Account summary** - totals across platforms: spend, conversions, CPA,
   each with both weeks' absolute values and the change.
3. **Per-platform detail** - one section per platform:
   - a table: spend, conversions, CPA for last week AND prior week
     (absolute values, then the change)
   - one sentence on what most likely drove the movement
4. **Recommendations** - exactly one actionable recommendation per platform,
   consistent with that platform's movement. A recommendation to change
   something must go through the writes skill (proposal, never direct action).
5. **Caveats** - data completeness, small-volume warnings, any metric that
   could not be reconciled across sources.

## Rules

- Every number in the report must be traceable to a tool result in the
  conversation. If you did not see it from a tool, do not write it.
- Percentages without absolute values are not allowed.
- Preserve each metric's source boundary (see the wiki).
- Keep the report scannable: tables for numbers, prose for interpretation.
